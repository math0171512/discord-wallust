This is the config I use to help match my Discord with Wallust. This really only uses your `foreground` and `background` colors.

[wallust](https://explosion-mental.codeberg.page/wallust/)

## Example config
`walust.toml`
```toml
[templates]
discord = {template="discord/discord.css",target="~/.config/vesktop/themes/Wallust.css"}
```
